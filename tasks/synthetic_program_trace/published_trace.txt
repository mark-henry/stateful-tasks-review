This example is chosen over the same paper's Figure 1 "remove_Occ" scratchpad example (a string-manipulation
function) because it is the closer match to the synthetic_program_trace task family: a small integer-variable
program with straight-line assignment/arithmetic (+=, *=) and ONE bounded while-loop, traced line-by-line with
full local-variable state after each executed line -- structurally identical to what this task's own generator
is meant to produce, per SOURCING.md and Bieber et al. 2020 (the synthetic-program corpus Nye et al. themselves
modified for this appendix, per their Section 5.1: "We use a dataset of synthetic Python programs modified from
Bieber et al. (2020). These programs include small integers (0, 1, and 2), simple while loops, and if
statements."). Also note: Table 2 (Section 5.1, "Synthetic tracing and execution results") reports quantitative
accuracy numbers for scratchpad vs. direct-prediction on exactly this synthetic-program family (see desk.json
published_data).

=== Prompt ===

Consider the following Python function:

def f(v0):
  v0 += 0
  v4 = 2
  while v4 > 0:
    v4 -= 1
    v0 *= 2
  return v0

output = f(6)

What is the execution trace?
